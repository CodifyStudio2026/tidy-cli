# tidy 🧹

یک ابزار خط فرمان (CLI) حرفه‌ای با پایتون برای **مرتب کردن پوشه‌ها**، **پیدا کردن فایل‌های تکراری** و **دیدن اینکه فضای دیسک کجا رفته**.
هیچ وابستگی بیرونی ندارد (فقط پایتون ۳.۹ به بالا) و **هر تغییری که ایجاد می‌کند با یک دستور قابل برگشت است**.

## نصب

```bash
cd tidy-cli
pip install .          # یا: pipx install .
tidy --version
```

بدون نصب هم می‌شود اجرا کرد: `PYTHONPATH=src python -m tidy_cli --help`

## دستورها

| دستور | کار |
|---|---|
| `tidy organize [پوشه]` | فایل‌های پخش‌وپلا را در پوشه‌های Images، Documents، Videos و... می‌ریزد |
| `tidy undo` | آخرین تغییر را کامل برمی‌گرداند |
| `tidy history` | فهرست تغییرات قبلی |
| `tidy dupes [پوشه]` | فایل‌های هم‌محتوا را پیدا می‌کند |
| `tidy stats [پوشه]` | حجم هر نوع فایل و بزرگ‌ترین فایل‌ها |
| `tidy watch [پوشه]` | پوشه را زیر نظر می‌گیرد و خودکار مرتب نگه می‌دارد |

### مثال‌ها

```bash
tidy organize ~/Downloads --dry-run       # فقط نقشه را نشان بده
tidy organize ~/Downloads                 # با تأیید تو جابه‌جا کن
tidy organize ~/Photos --mode date        # Photos/2026/09/...
tidy undo                                 # پشیمان شدی؟

tidy dupes ~/Documents --min-size 100KB
tidy dupes ~/Documents --move-to ~/dupes-box   # قابل برگشت با tidy undo
tidy dupes ~/Documents --delete                # حذف دائمی (با تأیید)

tidy stats ~ --top 15

tidy watch ~/Downloads --settle 15        # هر ۵ ثانیه چک می‌کند
```

حالت‌های `--mode`: `type` (نوع فایل)، `date` (سال/ماه)، `ext` (پسوند).

## چرا امن است؟

- **هیچ فایلی رونویسی نمی‌شود.** اگر اسم تکراری باشد، `name (1).ext` ساخته می‌شود.
- **همه‌چیز در ژورنال ثبت می‌شود** (`~/.tidy/journal.json`) و `tidy undo` پوشه‌های خالی‌شده را هم پاک می‌کند.
- **بدون تأیید چیزی جابه‌جا نمی‌شود** (مگر با `--yes`). در محیط غیرتعاملی (اسکریپت/cron) پیش‌فرض «انصراف» است.
- فایل‌های نیمه‌دانلودشده (`.crdownload`، `.part` و...) و فایل‌هایی که تازه تغییر کرده‌اند دست‌نخورده می‌مانند.
- لینک‌های نمادین (symlink) و فایل‌های مخفی نادیده گرفته می‌شوند.

## الگوریتم پیدا کردن تکراری‌ها

سه مرحله، از ارزان به گران: ۱) هم‌اندازه بودن ← ۲) هش ۶۴ کیلوبایت اول ← ۳) هش کامل (BLAKE2b).
بیشتر فایل‌ها در مرحله‌ی اول یا دوم حذف می‌شوند، پس روی هارد بزرگ هم سریع است.
از هر گروه، **قدیمی‌ترین** نسخه نگه داشته می‌شود.

## ساختار پروژه

```
src/tidy_cli/
  cli.py         دستورها و argparse
  organizer.py   برنامه‌ریزی، اجرا و برگشت جابه‌جایی‌ها
  dupes.py       پیدا کردن تکراری‌ها
  stats.py       آمار حجم
  journal.py     ژورنال تغییرات (برای undo)
  categories.py  دسته‌بندی پسوندها
  fsutil.py, ui.py
tests/           ۱۵ تست (unittest)
```

## تست

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
```

## ایده برای توسعه

- دسته‌بندی سفارشی با فایل تنظیمات `~/.tidy/config.toml`
- دستور `rename` برای تغییر نام گروهی با الگو
- اجرای `watch` به‌صورت سرویس (systemd / Task Scheduler)
- خروجی `--json` برای اتصال به ابزارهای دیگر
